BibFix

Cleans up your reference list.

Source on GitHub ↗

Reference lists get messy. Some titles are capitalised and some aren't, the same venue is written five different ways, preprints stand in for papers that came out a year ago, and now and then there's a citation that doesn't exist at all because a chatbot made it up.

BibFix tries to fix all of that in one place. It checks each entry against real records (DBLP and Crossref), not a language model, so every change comes from somewhere you can look up. You get back a plain .bib file and a list of what changed. Keep, undo or edit any of it.

To check a bibliography, install BibFix (below) and run bibfix check refs.bib.

What it reports

SafeSame paper; fields added or tidied. Applied by default.
arXivA preprint replaced by its published version. Applied by default.
ReviewTitle, authors or type differ, so possibly a different paper. Not applied.
Not foundNeither DBLP nor Crossref knows it. Check that it exists.
DuplicateOne paper cited under several keys.

Install

uv tool install git+https://github.com/narunraman/bibfixbibfix dblp-update      # downloads DBLP; rerun monthly

Use

bibfix check refs.bib --tex main.tex  # report onlybibfix fix refs.bib -i                # apply the safe and arXiv fixes

With Zotero: bibfix sync, bibfix push and bibfix add.
