Mâché

Write a LaTeX paper with an agent, and see what it changed.

Source on GitHub ↗

Asking an agent to tighten a section, or to answer a reviewer, is easy. Seeing what it did is not. In a .tex file a paragraph is one long line, so git diff tells you the whole paragraph changed when it was four words, and a paragraph it moved shows up as one deleted and another added.

Mâché is suggesting mode, the Google Docs kind, for a LaTeX paper in VS Code. The agent edits the files however it likes. You see its edits as suggestions in place, talk about them in comment threads it can read and answer, and nothing becomes part of the paper until you accept it.

removed added commented moved

Install

npm install -g github:narunraman/machemache setup    # the VS Code extension

Use

mache start     # in a paper: its current text becomes the accepted text

Comment on anything with Alt+M, then ask your agent, in whatever chat you already use, to go through your comments. It finds its way by running mache, which lists what's waiting for it. Accept, reject or reply to what comes back, and when the round is done:

mache commit    # one commit of the text you accepted

What it keeps

accepted textA copy of each file as you last accepted it. Anything that differs is a suggestion.
threadsYour comments and the agent's replies, attached to the words they're about or to an edit.
historyEvery edit, accept, reject and reply, in a private git history that stays on your machine.

All of it lives in a .review/ folder in the paper, out of git. Your repository only ever sees one tidy commit per round, with a message drafted from what happened in it.
